# 用户指南

双栏模型选择器用于 DeepSeek Harness Web 界面：弹层左栏浏览供应商，右栏展示该供应商的模型卡片。它复用宿主已有的模型目录和写回服务，不配置供应商凭证。

## 浏览与选择

1. 点击输入区的模型按钮，左栏列出供应商（当前供应商带“当前使用”蓝点），右栏默认显示当前供应商的模型。
2. 点击左栏其他供应商，右栏随之切换。浏览另一家不会改变会话正在使用的模型。
3. 点击右栏模型卡片进行选择。写回成功后菜单关闭，输入区显示新模型；失败时菜单保留并显示错误。
4. 点击菜单外部关闭菜单。

供应商的排列沿用宿主语义：DeepSeek 账号、官方供应商优先，其余保持目录顺序。模型在未搜索时保持目录顺序，当前项只作强调。

## 搜索

| 所在页面 | 搜索范围 |
|---|---|
| 模型卡片页 | 全部供应商的模型，结果卡片标注所属供应商 |
| 思考强度页 | 强度名称和 id |

搜索不区分大小写，支持连续子串和按顺序分散出现的字符；连续匹配优先，同分保持目录顺序。点击清除按钮或在有文字时按 Esc，可清空搜索并回到当前供应商的模型列表。

## 思考强度

当前模型声明支持推理时，弹层底部显示“思考强度”入口。点击后右栏变为强度档位列表；可选档位来自宿主目录。“供应商默认”仅在目录未声明默认强度时额外提供。

成功选择的偏好按供应商 + 模型在应用进程内记忆，切走再切回可以恢复。此偏好跨会话共享，但不会立即修改其他会话已保存的实际强度；应用重启后偏好记忆丢失，会话实际值仍以宿主恢复结果为准。

## 键盘

| 按键 | 行为 |
|---|---|
| Enter | 在模型按钮上打开菜单；确认高亮的模型 / 强度；在按钮上激活该按钮 |
| ↑ / ↓ | 移动右栏卡片高亮，到头循环，不提交选择 |
| Esc | 有搜索文字时先清空；思考强度页先返回模型列表；否则关闭菜单 |
| 空格 | 搜索框中正常输入，不激活插件按钮 |
| Tab / Shift+Tab | 无插件自定义快捷动作，保留控件原有的浏览器焦点行为 |

输入法组字期间，确认候选字不会触发插件选择。模型按钮不支持用 ↓ 或空格打开，Tab 不承担返回功能。

列表高亮与键盘焦点不同：打开后焦点通常在搜索框，方向键改变高亮；焦点在具体按钮上时，Enter 激活该按钮。原生焦点移出菜单和模型按钮时，现有失焦规则可以关闭菜单。

## 错误与恢复

- 切换被宿主拒绝时，菜单保留并提示错误；会话写入锁错误有专用提示。
- **选择失败条中的“重试”目前只重载目录。** 再次写回需要重新点击目标模型或强度。
- 目录服务不可用时，点击错误状态的模型按钮可查看、复制诊断信息；诊断面板的“重试”会重新解析目录服务。
- 目录可能来自本地配置或缓存，断网不一定阻止浏览或选择。消息发送失败由宿主按自身规则展示。
- 子代理会话中的模型按钮禁用。

## 安装、卸载与更新

本地源码安装方式见 [README](../README.md#安装)。安装、更新客户端或卸载后，重启整个 Harness，客户端模块无热重载。

```sh
dsh plugin --profile desktop remove @codewei823/dsh-model-picker-2level
```

示例使用 desktop profile；使用其他 profile 时替换名称。卸载并重启后应恢复宿主原有的模型选择器，内置 /model 命令保留。

当前限制和后续计划见 [路线图](../ROADMAP.md)。
