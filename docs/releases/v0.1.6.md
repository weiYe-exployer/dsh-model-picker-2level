## 安装

```sh
dsh plugin --profile desktop add @codewei823/dsh-model-picker-2level@0.1.6
```

按实际使用的 profile 替换 desktop，安装后重启整个 Harness。

旧的 @local/dsh-model-picker-2level 与正式包使用相同入口，不应同时保留。迁移时先移除旧包，再安装正式包并重启；本次发布不自动修改已有日常 profile。
