# v0.1.7 · 兼容 DSH 0.2.1-rc.5

日期：2026-11-06。正式包名：@codewei823/dsh-model-picker-2level。

运行功能沿用已验收的 v0.1.5 基线，未改动客户端代码；本次只放宽宿主版本声明。

- `engines.dsh` 从精确版本 0.2.1-rc.3 改为范围声明 `^0.2.1-rc.3`：0.2.x 全部版本（含 prerelease 与正式版）自动兼容，0.3.0 起的大版本更新仍被门禁拦截，需实机验证后再调整。
- 已在 DSH 0.2.1-rc.5（Windows 桌面宿主）实机核实：`conversation.input.model` 槽位与子槽位 `conversation.input.model.label` 的声明结构不变，`engines.dsh` 按 semver 范围（含 prerelease）判定。
- 宿主升级时的复验口径与豁免机制见 [架构说明](../architecture.md)。

## 安装

```sh
dsh plugin --profile desktop add @codewei823/dsh-model-picker-2level@0.1.7
```

按实际使用的 profile 替换 desktop，安装后重启整个 Harness。

操作与已知限制见 [用户指南](../usage.md) 和 [README](../../README.md)。
