# 版本存档：v0.1.5 基本功能定稿

- 日期：2026-10-27。
- 用户结论：基本功能完成，本版定稿。
- 版本：0.1.5，基于 v0.1.4 完成审视、修复与键盘简化。
- 本地归档标签：v0.1.5；包仍为 private，通过本地目录安装，未发布 npm。

## 定稿功能

- 供应商 → 模型两级浏览；浏览目标与当前使用的供应商分离。
- 首页搜索全部模型，模型页只搜索本家；强度页只搜索强度。
- 选择模型 / 强度通过宿主目录服务写回；成功后关闭，失败保留菜单。
- 思考强度按供应商 + 模型在应用进程内记忆，仅成功写回更新记忆。
- 会话切换重新绑定目录，隔离订阅与异步回调；重复提交互斥。
- 点击外部关闭、窗口变化跟随定位、主题令牌、目录诊断及重新解析入口。
- 子代理会话禁用选择。

## 最终键位

| 按键 | 行为 |
|---|---|
| ↑ / ↓ | 只移动列表高亮 |
| Enter | 打开菜单、进入供应商、确认模型 / 强度，或激活有焦点的按钮 |
| Esc | 搜索有文字先清空；为空时返回供应商首页，首页则关闭 |
| 空格 | 搜索框中输入文字；不激活插件按钮 |
| Tab / Shift+Tab | 无插件自定义动作，保留原有浏览器焦点行为 |

已移除 Tab 返回首页、↓ 打开菜单及空格激活。鼠标操作保留。

## 验证结果

自动化共 59 项：30 项纯函数 / 契约、8 项包结构、21 项真实 React + jsdom 交互。在 Windows 的 Node 20.20.2、22.23.4、24.14.0 下通过；清单与 JS 语法检查、git diff --check 通过。CI 配置覆盖 Node 20 / 22 / 24，未将本机结果表述为已运行远端 CI。

用户真实 Harness 反馈通过：

- 初始验收第 1 项（插件生效）与第 4 项（窗口、显示相关验收）。
- 模型切换与实际发送、强度与切回记忆、两个会话隔离。
- 断网与恢复、生成中尝试切换。
- 简化后的键盘测试。

具体供应商请求日志与是否实际触发 session/writer-held 错误码未单独记录。旧请求完成窗口、部分目录失败、目录不可用诊断及读屏未获得独立人工反馈，保留为条件场景，不扩大“全部验收通过”的范围。

## 保留限制与后续增强

- 选择失败条里的“重试”仅重载目录，再次写回需重新点击目标项；诊断面板“重试”则重新解析目录服务。
- 强度偏好记忆为进程内、跨会话共享；重启后丢失，各会话已保存的实际选择仍由宿主恢复。
- 插件 Config、动画和 aria-activedescendant 尚未实现；读屏单独追踪。
- 宿主升级后需复验 Slot 胜出规则、目录 API 和实际写回行为。

以上不纳入本次基本功能定稿的新增工作；后续变更从此版本继续演进。

## 开发、安装与回退

```powershell
cd D:/vibe_coding/dsh-plugin-develop
npm ci
npm run validate
npm test

# 本地目录安装，重启 Harness 后生效
dsh plugin --profile desktop add "D:/vibe_coding/dsh-plugin-develop"
```

本项目无构建步骤、无新增运行时依赖；React / ReactDOM 仍由宿主提供，仓库中的 devDependencies 仅用于测试。修改客户端后须重启 Harness。

需要查看定稿代码时可使用 git show v0.1.5:client.js。需要切换回本版时，先保存后续工作，再 git switch --detach v0.1.5，并重启 Harness。卸载方法沿用 [v0.1.4 存档第 6 节](v0.1.4.md#6-安装--卸载--回滚)。
