# v0.2.0 · 双栏卡片模型选择器

日期：2026-11-07。正式包名：@codewei823/dsh-model-picker-2level。

模型选择弹层改为双栏联动布局，取消"进入供应商子页 / 顶部返回"的逐级导航：

- 左栏供应商 rail：渐变 Logo、名称、模型数量与当前使用蓝点；点击只切换浏览，不提交选择。
- 右栏模型卡片：厂商色标、显示名与完整等宽 id；当前项品牌描边加对勾。
- 已知厂商固定语义色（字节=蓝、MiniMax=橙、通义=绿、DeepSeek=紫、Kimi=青、zai=品红），未知厂商按稳定哈希取色；色块与卡片底色以 color-mix 叠加主题 token，深浅主题均验证过对比度。
- 搜索统一跨全部供应商，结果卡片标注所属供应商；清空搜索恢复当前浏览供应商的列表。
- Esc 语义更新为：先清空搜索 → 思考强度页返回模型列表 → 关闭菜单；↑↓ 高亮作用于右栏卡片。
- 弹层默认宽度提高到 408–456px 以容纳双栏。

兼容性不变：`engines.dsh` 仍为 `^0.2.1-rc.3`；供应商与模型仍由宿主目录管理，`/model` 命令保留。

## 安装

```sh
dsh plugin --profile desktop add @codewei823/dsh-model-picker-2level@0.2.0
```

按实际使用的 profile 替换 desktop，安装后重启整个 Harness（客户端模块无热重载）。

界面示意与操作说明见 [README](../../README.md) 和 [用户指南](../usage.md)。
