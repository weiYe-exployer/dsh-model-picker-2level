# 测试与兼容性

## 自动化

在仓库根目录执行：

```sh
npm ci
npm run validate
npm test
```

测试使用 Node 内置 runner。React、ReactDOM、jsdom 仅为开发依赖，宿主运行插件时从自己的模块表提供 React。

v0.1.5 功能基线包含 59 项测试：30 项纯函数 / 契约、8 项包结构、21 项 React DOM 交互。交互测试模拟 Harness 服务，使用真实 React、portal、effect、订阅和事件冒泡；重试定时器与动画帧使用受控调度。

覆盖搜索、强度记忆、注册契约、键盘、输入法、外部关闭、失败恢复、连续提交、会话切换、旧请求完成和资源清理。新增发布校验工具检查文档链接与实际安装包内容，不混入功能测试数量。

## 人工验收清单

修改 client.js 后重启整个宿主，再按以下检查。测试使用可丢弃会话，发送简单短消息即可。

| 场景 | 检查方法 | v0.1.5 记录 |
|---|---|---|
| 加载与显示 | 安装、重启，查看两级选择器；检查窗口变化和亮暗主题 | 用户实测通过 |
| 模型与实际发送 | 选择两个不同模型，分别发送消息，检查会话显示；可观测时核对真实请求目标 | 用户实测通过，原始请求日志未附 |
| 强度与记忆 | 给支持推理的模型选档位，切走再切回 | 用户实测通过 |
| 会话隔离 | 两会话分别选择模型和强度，单独修改其中一个，检查另一会话已保存的值 | 用户实测通过 |
| 断网与恢复 | 分别观察目录、选择和发消息；联网后再操作 | 用户实测通过 |
| 生成中切换 | 生成期间尝试改模型 / 强度，检查允许或拒绝时的行为，完成后再试 | 用户实测通过；未单独确认 writer-held 错误码 |
| 简化键盘 | Enter 打开 / 确认；↑↓ 移动；Esc 先清搜索再返回；↓、空格、Tab 不承担旧快捷动作 | 用户实测通过 |
| 旧请求完成 | 提交后关闭重开或切会话，旧回调不关闭新菜单、不污染新会话 | 自动化覆盖，独立人工条件未触发 |
| 部分目录失败 | 用可恢复的测试供应商制造加载失败，检查其他供应商可用及恢复 | 待独立人工验证 |
| 目录不可用诊断 | 紧凑按钮打开完整诊断、可复制、恢复后可重试 | 自动化覆盖，待独立人工验证 |
| 读屏 | 检查焦点与高亮项宣布 | 未完成；aria-activedescendant 尚未实现 |

模型自报身份、回答长度和响应速度不能单独证明实际模型或强度参数。无法观察请求字段时明确记录；没有触发错误状态时记录“未触发”，不推断错误分支通过。

Tab 的原生焦点移动和按钮空格激活拦截需在真实浏览器确认，jsdom 只验证事件处理与状态变化，不进行真实布局或完整原生键盘默认动作。

## 安装包检查

```sh
npm run check:package
```

脚本实际生成临时 tgz、解包检查所有承诺文件与 Markdown 相对链接，拒绝依赖目录、环境文件和开发历史混入安装包，并清理临时产物。公开发布前还应在隔离 profile 中从拟发布源安装、卸载和重启验证，避免修改日常 profile。
